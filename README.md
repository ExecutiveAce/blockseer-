# BLOCKSEER 🚀🔍

BLOCKSEER is an AI-powered Bitcoin behavior prediction system.  
It analyzes historical data, visualizes key market trends, and forecasts market sentiment and price behavior using intelligent agentic pipelines.

---

## 🌟 Features

- 📊 Interactive dashboard with real-time Bitcoin visualizations
- 🧠 Predictive modeling based on sentiment, volume, and technical signals
- 🎯 Behavior classification & emotion-intent inference (coming soon!)
- 📁 Modular architecture for scalability and customization

---

## 🏁 How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Start the application:
python run.py


3. Explore the dashboard and visual insights (URL to be printed in terminal).
